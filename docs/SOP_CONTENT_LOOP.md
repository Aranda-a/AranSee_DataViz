# 内容生产 SOP（分析 → 拆解 → 修文 → 追更）

> 给 **Agent + 创作者** 用的可重复流程。  
> **Skill 交付物始终是** 单条 `analysis.json`；沙盘 HTML 仅展示，不在本 SOP 内强制生成。

---

## 目标

把「学爆款」变成固定回路，并可接到民俗恐怖等内容方向（如 Boobot）：

```
借鉴场内爆款 → AranSee 拆解 → 按 next_step 修文 → 定上下期钩子 →（可选）出绘图 brief
```

---

## 角色分工

| 角色 | 做什么 | 不做什么 |
|------|--------|----------|
| **AranSee Skill** | 读帖+评论 → 输出 `analysis.json` | 不爬取、不渲染沙盘、不替你拍板选题 |
| **创作者 / 你** | 选帖、确认脱敏、改稿、发帖 | 把模拟滑块当分当真分 |
| **沙盘（可选）** | 读 JSON 后的空间感知 / 策略模拟 | 不改变路径 1 真分 |
| **Boobot / 绘图（下游）** | 吃 `next_step` + 题材 brief 出图/脚本 | 不重新发明三轴 |

---

## 步骤（每次一条帖）

### 0. 选帖（人）

- 自用或公开页复制：正文 + **代表性评论**（含赞、问、争议、作者回复更佳）
- 禁止未授权批量爬取

### 1. 拆解（Agent · Skill）

1. 读 `prompts/score_content.system.md`  
2. 输入用户粘贴内容（或案例 `raw/`）  
3. **只输出一个** `analysis.json` 对象  

**验收：** 含 `coordinates.X/Y/Z.score`（0–100）+ `insight.next_step`（一句可执行）。

金样对照：

| 案例 | 轴型 | 路径 |
|------|------|------|
| 外部拍摄账号 | 高 Z 低 Y | `assets/cases/nature_cloud_photo_01/` |
| 档期科普 | 高 Z 偏低 Y | `assets/cases/market_festival_edu_01/` |
| 民俗解说（自用深度） | 三轴均衡偏热 | `assets/cases/folk_film_commentary_01/` |

### 2. 读诊断（人 · 90 秒）

- 看哪轴最低 / 哪轴过高  
- 只采纳 **一条** `next_step` 进本轮改稿（避免一次改三轴）

例（云朵帖）：Z88 Y24 → 下条加「陪一张」或拍摄时段，**轻抬 X，不推货**。

### 3. 修文（人 + 可选 Agent）

| 若要抬 | 改稿抓手（示例） |
|--------|------------------|
| X 结构 | 时序提示、清单一句、置顶说明、系列编号 |
| Y 商业 | CTA、组件复用、置顶带货（慎用；氛围帖常应保持低 Y） |
| Z 情感 | 互动钩子、陪晒引导、作者回复话术 |

输出：修订后的正文 / 分镜要点（仍是人确认后发布）。

### 4. 追更上下期（人）

- 上期诊断 → 下期只补最短板或延续最强轴  
- 民俗恐怖系列可对照 `folk_daoxi_series_01` 的 A/B 漂移读法（展示用）

### 5. 可选 · 绘图 brief（下游）

从 `analysis.json` 抽：

- `vibe_tag`  
- `insight.next_step`  
- 需要强调的轴（例如「氛围为主，勿出现硬广道具」）

交给绘图 / Boobot 工作流；**AranSee Skill 本身不产出图片。**

---

## 调用话术（给 Agent）

```
按 AranSee Skill：读 prompts/score_content.system.md，
对我粘贴的这一条帖+评论输出单个 analysis.json（符合 DATA_CONTRACT）。
不要渲染沙盘，不要长报告。
```

修文轮：

```
基于上一条 analysis.json 的 next_step，只改一处结构/互动钩子，
给出修订正文草案；不要重算三轴除非我提供新评论。
```

---

## 明确交付物

| 阶段 | 交付物 | 是否 Skill 承诺 |
|------|--------|-----------------|
| 拆解 | **`analysis.json`（单对象）** | **是 · 唯一** |
| 修文 | 修订正文 / 分镜要点 | 否（人+Agent 协作） |
| 展示 | 预烘焙沙盘 HTML | 否（Pages / 完整仓） |
| 绘图 | 图像 / 脚本 | 否（下游） |
