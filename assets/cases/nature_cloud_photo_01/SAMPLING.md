# 评论抽样说明 · nature_cloud_photo_01

**原则：** 公开包只保留**类型代表**，不保留可识别昵称与原图链接。全量评论不进 Git。

| 类型 | 作用 | 对三轴的影响倾向 |
|------|------|------------------|
| emoji / 短赞 | 气氛 | 抬 Z |
| 祝福 / 感叹 | 气氛 | 抬 Z |
| 「也想拍」「好美」 | 参与欲 | 抬 Z |
| 「陪一张」晒图 | 共创 | **强抬 Z** |
| 作者暖回 | 关系维护 | 抬 Z；商业仍低 |
| （样本中少见）地点/参数追问 | 信息结构 | 若增多可抬 X |

**局限：** 若截图未含水评 / 质疑 / 广告评论，**Z 可能略偏高**（已写入 `insight.sampling_caveat`）。
